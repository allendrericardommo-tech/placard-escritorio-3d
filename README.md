# Placard con escritorio · 4 propuestas en 3D

Obra Patagona 3 · Coyhaique.

Modelo 3D interactivo de las cuatro propuestas (A, B, C y D) para el placard con escritorio.
Se abre en cualquier navegador, en computadora o celular.

- Girar: arrastrar con el mouse o con un dedo.
- Acercar: rueda del mouse o pellizco.
- Botones: Abrir / Cerrar, Luz LED, Noche y Medidas.
- Enlace directo a una propuesta: agregar #a, #b, #c o #d al final de la dirección.

Medidas en cm. Pared revestida de 251,5 y cielorraso a 260. Enchufe a 130 cm, centrado en la pared.
